# Security Policy

Nyxvion OS is built from the ground up to be an impenetrable digital fortress. Security and privacy are not just features; they are the core foundation of our browser.

## Supported Versions

Currently, Nyxvion OS is in the **Pre-Alpha** stage. We actively monitor and patch critical security vulnerabilities for the latest experimental builds.

| Version | Supported |
| ------- | ------------------ |
| v0.1.x (Pre-Alpha) | :white_check_mark: |
| Older Builds | :x: |

## Reporting a Vulnerability

We take all security issues seriously. If you discover a vulnerability, **do not open a public issue.** Public disclosure puts our early adopters at risk.

Please report any suspected security vulnerabilities or bypasses in the Nyxvion Shield engine directly to our security team via email:
**contact@nyxvion.com**

### What to Include:
*   Detailed description of the vulnerability.
*   Steps to reproduce the issue.
*   Your operating system and Nyxvion OS build version.

We aim to acknowledge all reports within 48 hours and work with you to resolve the issue swiftly before any public disclosure.
